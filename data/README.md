# Public data layer

The `data` directory contains public geography and metadata used by the Results Explorer.

## Geography

- `existing_grid_138_230_500.geojson`
- `ecuador_colombia_peru_boundaries.geojson`
- `paramo_nodes_georeferenced.csv`
- `paramo_lines.csv`
- `international_interconnections.csv`
- `generation_plants_public.csv`
- `zone_registry.csv`

The chart-ready result bundle is loaded from the versioned JavaScript file in `assets/js`.
