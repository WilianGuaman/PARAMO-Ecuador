# Dashboard guide

Use the left panel to select the case, pathway, hydrology, statistic, year and month.

## Map controls

- **Existing 138/230/500 kV grid** — georeferenced physical transmission network.
- **PARAMO reduced network** — 24N planning branches or 6N equivalent corridors.
- **Reduced-model nodes** — active model nodes.
- **Reference plants** — contextual generation facilities.
- **Colombia / Peru links** — external-system connections.

The 24N map shows the model topology. The 6N map also reports corridor capacity and expansion state by year.
