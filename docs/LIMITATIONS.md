# Limitations

## Ecuador 24N

- Transmission investments are available by cost component, not by optimized branch and year.
- Reservoir operation is aggregated; plant-specific storage and hydraulic transfers are unavailable.
- The supplied 24N files contain positive 2025 build activity and differ from the historical-year convention used in the 6N case.
- The Baseline and Adverse ensembles originate from separate result packages and should be interpreted as distinct hydrological cases.

## Ecuador 6N

- The reduced network is an equivalent planning representation.
- Hydraulic detail is shown for selected reservoirs and cascades available in the output layer.

## Map

Physical lines and PARAMO branches are different layers. A reduced planning branch is not a one-to-one physical transmission line.
