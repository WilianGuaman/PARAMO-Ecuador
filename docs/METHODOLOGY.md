# Methodology

PARAMO is a long-term generation and transmission expansion planning framework for hydro-dependent power systems.

## Ecuador 24N

The 24N application evaluates REF, BRIDGE and NZT under Baseline and Adverse hydrology. Ensemble statistics are reported as Mean, P10, P50 and P90. A representative realization supports monthly operation and plant-level generation views.

## Ecuador 6N

The 6N application evaluates BAU and REN100 under Normal and Extreme hydrology. Results include generation expansion, corridor-year transmission decisions, reservoirs and selected hydraulic cascades.

## Map

The physical layer uses the georeferenced 138, 230 and 500 kV network. The reduced planning layer is shown independently for the selected case.
