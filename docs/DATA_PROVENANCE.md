# Data provenance

## PARAMO results

The explorer uses precomputed PARAMO outputs prepared for the Ecuador 24N and 6N study cases.

## Physical transmission network

The map layer is derived from `Lineas.geojson`. The source CRS is EPSG:32717; the public layer is transformed to EPSG:4326 and restricted to 138, 230 and 500 kV.

## Planning networks

The 24N layer contains 24 nodes and 30 planning branches. The 6N layer contains the equivalent zonal nodes and seven corridors, including the Colombia and Peru connections.

## Country boundaries

Ecuador, Colombia and Peru context is based on Natural Earth low-resolution country boundaries.
