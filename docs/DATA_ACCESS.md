# Data access

## Public visualization layer

The PARAMO Ecuador Results Explorer is hosted as a static GitHub Pages application. Any value delivered to a web browser can be inspected by a technically capable user. For that reason, the public bundle contains only the aggregates and selected diagnostics required to render the explorer.

The public layer includes, as applicable:

- scenario-level cost, emissions, reliability and expansion indicators;
- annual and monthly chart-ready system series;
- technology/fuel-resource aggregates;
- 24-bus aggregate transmission-investment statistics and system-level reservoir/hydropower uncertainty;
- 6-bus corridor-level expansion and loading indicators;
- 6-bus reservoir results and selected cascade-hydraulic diagnostics;
- the mainland Ecuador outline, existing 230/500 kV grid and reduced-network geography.

The public layer does not include the complete PARAMO research database.

## Material available by request

Depending on the research purpose and redistribution constraints, a request may cover additional result tables or supporting data that are not included in the browser bundle. The PARAMO optimization implementation, confidential material, licensed third-party material and other non-redistributable assets are not automatically available through this process.

## Request procedure

1. Open the [PARAMO data-access request form](https://github.com/WilianGuaman/PARAMO-Ecuador/issues/new?template=data-access-request.yml).
2. Identify the study case and the variables/data categories required.
3. Briefly describe the intended research or educational use.
4. Confirm that the repository and associated methodology will be cited where appropriate.
5. The request is reviewed before any additional material is shared.

Approval is not automatic and may depend on the requested scope, provenance, third-party terms and the intended use.

## Privacy

GitHub Issues are public. Do **not** include passwords, confidential information, unpublished proprietary data, personal identification numbers, private email addresses or other sensitive information. If a request is approved, delivery can be coordinated separately by the repository maintainer.

## Citation

Use of PARAMO-derived material should identify the release and follow [`CITATION.md`](CITATION.md). Third-party reference records retain their original provenance and licensing conditions.
